# Classic-ML-REG
price - цена в долларах США (326-18 823 долл.) - целевая переменная

carat - вес бриллианта в каратах (0,2-5,01)

cut - качество огранки (Справедливая, Хорошая, очень хорошая, Премиум, Идеальная)

color - цвет бриллианта, от J (наихудший) до D (наилучший)

clarity - показатель чистоты бриллианта (I1 (наихудший), SI2, SI1, VS2, VS1, VVS2, VVS1, IF (наилучший)).

x - длина в мм (0--10,74)

y -  ширина в мм (0--58,9)

z - глубина в мм (0--31,8)

depth - общая глубина в процентах = z / среднее значение(x, y) = 2 * z / (x + y) (43--79)

table - Ширина огранки бриллианта, выраженная в процентах от его среднего диаметра

### Состояние данных:
Пропуски: Прямых пропусков (NaN) в данных нет.

### Взаимосвязи признаков:
Наблюдается сильная, очевидная зависимость цены(price) от размеров камня (x,y,z). Так же качество огранки(cut) сильно зависит от общей глубины(depth).

### В рамках проекта были выполнены следующие преобразования:

Действие: Данные были разделены на train и test в соотношении 80/20.

Действие: Для категориальных признаков ('cut', 'color', 'clarity') было применено Порядковое кодирование.

Причина: Некоторые модели не могут напрямую работать с категориальными строками.

Инструмент: Все преобразования (кодирование) были объединены в ColumnTransformer внутри Pipeline. Это позволяет применить одинаковые преобразования к обучающей и тестовой выборкам без утечки данных.

### Гиперпараметры
Для подбора использовался Grid Search с параметрами:
  1. Контроль сложности модели и переобучения
    1.1 "LGBMRegressor__num_leaves": [7, 15, 31],  # Максимальное количество листьев в дереве (влияет на сложность модели)
    1.2 "LGBMRegressor__max_depth": [3, 5, 7, 9],     # Максимальная глубина дерева (ограничивает сложность)
    1.3 "LGBMRegressor__min_child_samples": [5, 10, 20],  # Минимальное количество данных в листе (контроль переобучения)
    
  2. Скорость обучения и количество итераций бустинга
    2.1 "LGBMRegressor__learning_rate": [0.01, 0.05, 0.1],  # Скорость обучения (шаг градиентного спуска)
    2.2 "LGBMRegressor__n_estimators": [10, 20, 30, 40, 50, 100, 200],  # Количество деревьев в ансамбле

  3. Регуляризация
    "LGBMRegressor__reg_lambda": [0, 0.1, 1],  # L2-регуляризация (ридж)

Лучший набор параметров:
  1. 'LGBMRegressor__learning_rate': 0.1,
  2. 'LGBMRegressor__max_depth': 7,
  3. 'LGBMRegressor__min_child_samples': 10,
  4. 'LGBMRegressor__n_estimators': 200,
  5. 'LGBMRegressor__num_leaves': 31,
  6. 'LGBMRegressor__reg_lambda': 1

Это дало прирост 8.733207 на MAE и 9.068067 RMSE.
